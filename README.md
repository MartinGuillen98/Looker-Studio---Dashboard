# 🎯 Business Objective

The objective of this project is to analyze the performance of teams and players throughout the UEFA Champions League season by transforming raw football statistics into meaningful and interactive visualizations.

---

# 📂 Dataset

### Source

🔗 [Official UEFA Champions League statistics](https://www.uefa.com/uefachampionsleague/)

### Dataset Description

Unlike the other projects in this portfolio, no pre-built dataset was available for this analysis. I collected the data manually from the official UEFA website and structured it into a dataset suitable for analysis and visualization.

The dataset includes statistics such as:

- Teams
- Players
- Goals
- Assists
- Matches Played
- Cards
- Shots
- Possession
- Competition Statistics

### Why I chose this dataset

This was my first dashboard project using Looker Studio. I chose a football dataset because it is a topic I enjoy and understand well, allowing me to focus on learning dashboard development while working with familiar data.

---
# 🛠 Methodology

### Data Collection

- Collected official statistics from the UEFA website.
- Organized the information into a structured dataset.
- Standardized the data for analysis.

### Data Understanding

- Reviewed the dataset structure.
- Identified the main performance metrics.
- Defined the dashboard objectives.

### Data Preparation

- Validated data consistency.
- Reviewed data formats.
- Prepared the dataset for Looker Studio.

### Exploratory Data Analysis

Analyzed relationships between:

- Team performance
- Player statistics
- Goals and assists
- Match results
- Offensive and defensive metrics

### Dashboard Development

Developed an interactive dashboard including:

- KPI Cards
- Team Rankings
- Player Performance
- Competition Statistics
- Interactive Filters

### Business Analysis

The dashboard allows users to compare team and player performance throughout the competition, helping identify top performers and key trends during the tournament.

---

# 💡 Key Insights

- A small group of teams concentrated most offensive statistics.
- Top players consistently led multiple performance metrics.
- Teams with greater offensive efficiency generally achieved better results.
- Interactive filters allow quick comparisons across teams and players.
